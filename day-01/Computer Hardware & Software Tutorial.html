🖥️ Hardware, software and how they work together

You are the new junior technician in the campus computer lab. A PC has arrived in a box. Before you can build it, fix it or install anything on it, you need to know what every part does.

Two halves of every computer

🔩 HardwareThe physical parts. You can touch them, drop them and break them.
💿 SoftwareThe programs: sets of instructions that tell the hardware what to do. You cannot touch them.
Think of it like this A taxi is hardware. The route in the driver's head is software. A taxi with no route goes nowhere, and a route with no taxi carries nobody. A computer needs both.
Quick test: if you can pick it up, it is hardware. If you can only install, open or delete it, it is software.

    ⚙️ How the hardware runs a program

    A CPU does only one thing, billions of times per second: fetch an instruction, decode it, execute it. Watch one tiny program run in slow motion.

    This program adds 5 + 3, stores the answer and shows it. Press Step and follow the gold dot between RAM and the CPU.

    System software and application software
